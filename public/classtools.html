What it does

  1. Scaled rulers: rulers drawn to scale on screen, so you can measure and show lengths to the class.
  2. Interactive shapes: move and explore shapes in front of the class.
  3. Demo calculator emulator: a calculator on screen that you can use to demonstrate key presses, for example on the fx-83GT CW+.
  4. Always-visible learning objectives: keep the lesson objectives on screen while you teach.
  5. PDF and document pen: write on worksheets and documents as you go through them.
  6. Timer and screen pen: a classroom timer, plus a pen you can draw anywhere on the screen.

Download and set up

  1. Click Download ClassTools (ZIP) above. The file will save to your Downloads folder.
  2. Right-click the ZIP file and choose Extract All. Pick a folder you'll remember, such as Documents.
  3. Open the folder you extracted and double-click ClassTools to start the app.
  4. If Windows shows a "Windows protected your PC" warning, click More info, then Run anyway. This happens with apps that aren't widely downloaded yet.
  5. To keep it handy, right-click the ClassTools icon on your taskbar while it's running and choose Pin to taskbar. It will then be one click away every lesson.
