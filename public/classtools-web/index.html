ClassTools

Running in your browser — nothing to install, nothing for IT to approve.

Presenter Open a PDF or start on blank paper and write over it. Pen, shapes, text, ruler, protractor, compass, tracing paper and the mirror. Save your marked-up copy. Calculator Three scientific models laid out like the ones your learners hold, and a plain four-function desk calculator. Big enough to read from the back. ShapeXplorer Build a 2D shape on a dot grid, cut it at any angle, then turn it into a solid and spin it round. Timer A countdown you can read from anywhere in the room.

Keep it on your desktop

In Chrome or Edge, open the browser menu and choose Install or Add to Home screen. You get an icon and its own window with no address bar — and because it is still the browser, it needs no admin rights and nothing from IT.

What needs the Windows app

Two things a browser tab cannot do, because a tab is not allowed to draw outside itself: floating over PowerPoint, and the screen pen that writes over whatever is on screen — a website, a video, the visualiser.

Everything else on this page is the same code the Windows app runs. If you can install software on your machine, the Windows version adds those two and puts the whole lot on a dock.
